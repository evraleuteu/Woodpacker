# Spaced Compression System

## Purpose

Compress large learning materials into manageable mastery sessions.

## Example

### Input
500-page textbook

↓

50 knowledge units

↓

30-minute daily session

## Compression Layers

1. Extraction
2. Grouping
3. Prioritization
4. Scheduling
5. Repetition

## Speaking Compression (NEW)

Each speaking exercise follows the Woodpecker Speaking Cycle:

- Cycle 1: Full audio + transcript + translation + full hints
- Cycle 2: Audio + keywords only
- Cycle 3: Audio only, no transcript
- Cycle 4: Question only, no audio
- Cycle 5: Real-world scenario, no hints, fully spontaneous

## Learning Objective

Maximum retention with minimum study time.
