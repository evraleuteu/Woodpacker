# Product Requirements Document

## Problem

Students consume information but fail to retain it.

Most learning materials are designed for exposure, not mastery.

## Solution

AI converts learning materials into Woodpecker mastery cycles for language learning.

## Supported Inputs — Language Learning

### Documents
- PDF (textbooks, workbooks)
- EPUB (language course books)
- DOCX (study notes)
- TXT (transcripts, vocabulary lists)
- Markdown

### Audio
- MP3 (lesson recordings, podcasts)
- WAV
- M4A

### Images
- PNG
- JPG
- JPEG (textbook scans)

### Bundles
- ZIP (full course materials)

## Core Modules — Language

### Book Analyzer

Extracts:
- Chapters
- Lessons
- Exercises
- Vocabulary
- Grammar points
- Dialogues

### Accent Analyzer

Extracts:
- Pronunciation patterns
- Mispronunciations
- Stress patterns
- Intonation patterns

### Speaking Generator

Automatically generates from language materials:
- Recall questions
- Speaking prompts
- Pattern drills
- Roleplay scenarios (restaurant, hotel, doctor, etc.)
- Monologue topics
- Retelling exercises
- Pronunciation exercises

### Exercise Generator

Creates:
- Vocabulary exercises
- Grammar exercises
- Speaking exercises
- Writing exercises
- Listening exercises
- Pattern exercises

### Woodpecker Scheduler

Creates repetition cycles optimized for language retention.

### Speak Until Mastered Engine

Speaking exercises require mastery criteria before advancing:
- Pronunciation score ≥ 90%
- Grammar accuracy ≥ 95%
- Fluency score ≥ 85%
- Correct meaning conveyed
