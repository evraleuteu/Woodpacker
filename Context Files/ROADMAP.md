# Roadmap

## Phase 1 — Foundation (Months 1–3)

### Goal
Launch the first Woodpecker engine for language learning.

### Features
- PDF Upload (textbooks, workbooks)
- OCR
- Exercise Extraction
- Exercise Classification
- Daily Sessions
- Basic Scheduling
- Language detection

## Phase 2 — Language Core (Months 4–6)

### Features
- Vocabulary Decks
- Grammar Decks
- Listening Decks
- Speaking Decks
- Pattern Extraction
- Speaking Generator
- Audio Recall Mode
- Pattern Mastery Mode

### Goal
Become the best textbook-to-language-mastery platform.

## Phase 3 — Speaking Mastery (Months 7–9)

### Features
- Voice Response Mode
- Speak Until Mastered Engine
- Adaptive Speaking Feedback
- Pronunciation Engine
- Grammar Analyzer
- Fluency Analyzer
- Woodpecker Speaking Cycles

### Goal
Create the first content-driven Speaking Mastery System for language learners.

## Phase 4 — Accent Mastery (Months 10–12)

### Features
- Voice Upload
- Accent Analysis
- Pronunciation Detection
- Shadowing Exercises
- Accent Woodpecker Cycles

### Goal
Create the first Accent Woodpecker System for language learners.

## Phase 5 — Multi-Language Intelligence (Months 13–15)

### Features
- Multi-Book Fusion
- Multi-Source Learning
- Cross-Material Pattern Detection
- Unified Knowledge Graph
- Cross-Material Speaking Drills

### Goal
Build a Universal Language Mastery Engine.

## Phase 6 — Knowledge Mastery (Premium — Year 2)

### Features
- Knowledge Unit Extraction for non-language subjects
- Medicine, Engineering, Law, Nursing, Certifications
- Recall systems for technical content
- Exam preparation mode

### Goal
Expand beyond language into professional knowledge mastery.

## Phase 7 — Enterprise & Education (Year 2+)

### Features
- Teacher Dashboard
- Classroom Management
- School Accounts
- Progress Reports
- Institution Analytics
- Class Speaking Sessions

### Goal
Become the operating system for mastery learning across language education and professional training.
